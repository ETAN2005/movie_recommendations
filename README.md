## Movie Recommendations System 
Built a Python-based recommendation engine that suggests movies to users based on their viewing history and preferences. 
## Motivation
This project was built to explore how recommendation algorithms work in real-world applications like Netflix and Spotify. It helped me understand collaborative filtering, similarity metrics, and user-based prediction models. 
## Features
- Recommends movies using collaborative filtering
- Uses cosine similarity to find similar movies
- Displays top ten movie suggestions
- Integrating web interface (in progress)
## Tech Stack 
- Python
- TMDB API
